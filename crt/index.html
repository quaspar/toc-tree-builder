    Current Reality Tree

    A CRT explains how a few root causes produce the undesirable effects (UDEs) you observe. It is read bottom-up as sufficiency logic: IF cause THEN effect. An ellipse across several arrows means the causes are only sufficient together (logical AND).

    Suggested process

    1. List 5–10 UDEs: real, observable, negative effects stated as present-tense facts.
    2. Connect them: for each UDE ask “why does this exist?” and add causes below it (drag the bottom dot).
    3. Read every connection aloud (the inspector shows the IF…THEN sentence) and scrutinize it with the Categories of Legitimate Reservation.
    4. Where one cause is not enough, add the missing cause and tie the arrows with an AND.
    5. Keep going down until you reach entities with no causes inside your span of control: the root causes.
    6. The overview lists every root cause and how many UDEs it reaches. The core problem is usually the one reaching most UDEs (a common rule of thumb is ≥ 70%). Mark it as core.

    Mouse & keyboard

    • Double-click empty canvas: new entity. Double-click an entity: edit its text.
    • Drag an entity to move it; drag empty canvas to pan; wheel to zoom.
    • Top dot → drop on an effect. Bottom dot → drop on a cause. Drop on empty space to create the new entity there.
    • Click an arrow to select it; tick other incoming arrows to make them an AND group.
    • Shift+click to multi-select, Shift+drag to box select.
    • Del delete · Ctrl/⌘ Z undo · Ctrl/⌘ Shift Z redo · N entity · U UDE · F fit · T trees · Esc deselect

    Several trees

    Open ☰ Trees (or press T) to see every tree you have, search them, and create, open, rename, duplicate or delete trees. Each tree keeps its own zoom, position and undo history while you switch. The address bar links to the open tree (#tree=…), so you can bookmark a tree or keep different trees open in different tabs; tabs stay in sync.

    Storage

    Trees are saved automatically in this browser's localStorage. Nothing is sent to a server. Storage belongs to this site and this browser, so another browser or computer starts empty. Use Export all for backups and Import to move trees between machines. Trees made with the offline crt.html file live in that file's own storage: export them there and import them here.
